# 图像与版式设计简报

## 1. 认知目标

- 读者：
- 页面 / 文章 / 活动：
- 视觉任务（封面 / 解释 / 分隔 / 情绪 / CTA）：
- 对应段落或请求：
- 读者看完应得到什么：

## 2. 投放条件

- 渠道：
- 实际显示位置与尺寸：
- 画幅 / 分辨率 / 格式：
- 安全区 / 裁切 / 出血：
- 深色或浅色主题：

## 3. 内容与视觉方向

- 主体与动作：
- 必要对象与关系：
- 角度 / 视点 / 留白：
- 材质 / 光线 / 色彩 / 密度：
- 品牌或渠道视觉规则：
- 可借鉴的参考资料及可借鉴点：

## 4. 不得出现

- 文字 / 数字 / Logo / 水印：
- 不得虚构的人、产品、事件或界面：
- 不合适的风格与装饰：
- 版权、隐私与商标限制：

## 5. 可编辑文字

- 标题：
- 次级信息：
- 数据 / 来源：
- CTA / 地址 / 日期：
- 法律说明与小字：

## 6. 交付与验收

- 原始图像路径：
- Imagegen JSON 或授权记录：
- 设计源文件：
- 导出文件：
- 替代文本 / 图注：
- 裁切、压缩、转码状态：
- 尚未验证的事项：
