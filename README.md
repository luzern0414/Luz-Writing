# Luz Writing

写给一个读者、一个目的、一个渠道的中英文写作技能：事实可查，表达自然，只交付要的内容。

## 能做什么

- **起草与改写**：科技资讯、营销文案、观点与科普、故事与小说、学术与专业文档，以及各平台的标题、摘要和格式适配。
- **事实核查**：数字、引语、日期、名称逐条对应来源；搜索摘要只算线索；查不到的内容标成“待核实”，不编造。
- **去机器腔**：改掉空话、套话、排比堆砌和报告腔，没问题的句子原样保留，不矫枉过正。
- **只交付所要**：要几条、多长、什么格式就给什么，不附建议、评分、改动说明或备选版本。
- **成稿与配图**：成稿打包成一个阅读型 HTML，版式遵循 Luz-Design；需要封面时从风格菜单选风格（默认 3D 潮玩、软陶质感），用本机图像生成服务出无文字底图。
- **越用越懂你**：每次调用后记下偏好、有效来源和教训，下次先查再写。

## 适合 / 不适合

适合：以文字为主的交付，包括文章、文案、标题、摘要、脚本、审稿和事实核查，以及文章自带的封面和插图。

不适合，请转到：

- 海报、品牌主视觉、文档与表格版式的设计细节 → Luz-Design
- 产品界面、系统方案、原型和硬件选型 → Luz-System
- 后端开发、部署和上线 → Luz-Dev（上线用的协议和文案仍由本技能写）
- 网页检索与采集 → Luz-Crawl（本技能调研时会调用它）

## 快速开始

1. 把本目录放进 Agent 的技能目录（例如 `~/.claude/skills/luz-writing`）。
2. 准备 Python 3.11 及以上。调研需要 [Luz-Crawl](https://github.com/luzern0414/Luz-Crawl)，排版与海报需要 [Luz-Design](https://github.com/luzern0414/Luz-Design)；配图是可选能力，需要本机的图像生成服务。
3. 直接用一句话提需求，例如：
   - “把这几条发布会信息写成一篇公众号科技快讯，配一张封面。”
   - “这段读起来太像机器写的，只改这一段。”
   - “给这个产品写三条小红书标题。”
   - “核查一下这篇稿子里的数据和引语。”

安装后可以先跑一次自检：

```text
python -X utf8 scripts/01-validate_skill.py
```

## 工作方式

1. **查经验**：先在经验库里搜索这次的话题和渠道，沿用已记下的偏好。
2. **定任务**：判断是起草、改写、定点修改还是审稿，只读取对应的写作指南。
3. **找依据**：需要事实时用 Luz-Crawl 读原文，建立“说法、来源、限制”对照表。
4. **起草与修订**：从主旨、结构、段落到句子、用词、标点，由大到小改。
5. **过质量关**：事实、表达、格式和“只交付所要”逐项检查。
6. **交付**：每个任务一个目录，只交付一个 HTML，资料、草稿和图片放在旁边的 `raw/`。
7. **沉淀**：结束前把新偏好、有效来源和教训写回经验库。

## 经验沉淀

每次调用结束前，技能把三类内容写进 `experience/experience.json`：用户说过或纠正过的偏好、证明有效或无效的来源与参数、从失败里得到的教训。每条经验有一个话题 key，同一话题再次出现时新说法直接替换旧说法，只留一条旧文备查，不会越积越多。偏好最多 60 条，教训和有效信息各 120 条，超出时先删用得最少、最久没确认的。仓库公开，经验库不收姓名、联系方式、客户名和私人路径。

## 目录结构

```text
SKILL.md       技能入口：路由、忠实原文规则、写作流程、每次调用后沉淀
references/    17 份写作指南，按需读取（含封面与插图风格菜单）
assets/        阅读型 HTML 模板、正文格式示例、视觉生产简报
scripts/       技能自检、文章打包、会话管理、经验库及其测试
experience/    经验库 experience.json 与自动生成的 catalog.md
examples/      一篇完整的科技资讯示例
evals/         人工评审方法与回归用例
```

## 五个技能的分工

| 技能 | 负责 |
| --- | --- |
| [Luz-System](https://github.com/luzern0414/Luz-System) | 产品系统设计：需求、方案、功能清单、产品界面、原型、硬件选型 |
| [Luz-Design](https://github.com/luzern0414/Luz-Design) | 视觉标准与版式：配色、字体、图标、海报、文档与表格排版 |
| [Luz-Dev](https://github.com/luzern0414/Luz-Dev) | 从设计到上线：后端、接口、数据库、部署、资质与验收 |
| [Luz-Writing](https://github.com/luzern0414/Luz-Writing) | 写作：起草、改写、核查、去机器腔、文章封面与插图 |
| [Luz-Crawl](https://github.com/luzern0414/Luz-Crawl) | 检索与采集：用真实浏览器读取页面、媒体和评论 |
