# 03 · 选题策略与结构

## 内容是否有存在理由

每篇内容至少提供一种价值：

- 回答一个具体问题。
- 提供别人尚未提供的证据、数据、案例或方法。
- 给读者一个可执行步骤。
- 改变读者的解释框架。
- 让读者更准确地理解一个事件或人物。
- 在叙事中提供可感知的体验与回报。

如果内容是搜索型，写出一句“信息增量”：相比当前主要结果，这篇多了什么。没有增量时，不写第十一个同题版本。

## 主题规划

### 内容支柱

选择三到五个与读者问题、作者能力、渠道目标和可验证材料相符的主题。每个支柱下再分选题。

### 搜索型与传播型

- 搜索型：满足已存在的明确需求；标题、导语和前几段直接回答问题。
- 传播型：提出新解释、真实冲突、反直觉结果、具体故事或强观点。
- 两者兼有：开头解决搜索问题，中段提供新的证据或判断。

初始内容组合可按 60% 搜索、30% 传播、10% 实验规划；这是起点，用户目标和现有数据优先。

### 选题评分

按成功标准加权，可用：

| 维度 | 要问 |
| --- | --- |
| 读者影响 40% | 问题多久出现一次，后果多大 |
| 内容匹配 30% | 作者是否能提供独特证据或经验 |
| 需求与分发 20% | 搜索、社群、邮件或平台需求是否存在 |
| 生产成本 10% | 调研、采访、制作和复核是否可控 |

分数用来排序，不用虚构精确性。总分接近时优先能核实、能尽快验证的内容。

## 结构选择

| 任务 | 常用骨架 |
| --- | --- |
| 新闻 | 触发事实 → 背景与机制 → 影响 → 边界/下一步 |
| 技术解释 | 现象 → 生活类比 → 真实机制 → 影响 → 限制 |
| 观点 | 冲突命题 → 隐含前提 → 反证/因果 → 新判断 → 边界 |
| 教程 | 前置条件 → 步骤 → 结果验证 → 失败处理 |
| 产品文案 | 问题/结果 → 机制 → 证据 → 异议处理 → CTA |
| 案例 | 情境 → 目标 → 选择 → 行动 → 结果 → 适用边界 |
| 提案 | 背景 → 问题 → 方法 → 交付 → 时间 → 风险 → 决策请求 |
| 学术 | 问题 → 缺口 → 方法 → 证据 → 贡献 → 限制 |
| 故事 | 欲望 → 阻碍 → 选择 → 后果 → 未完成期待 |

选择相邻内容之间的关系：因果、递进、对照、让步、并行任务、同一条人物弧线。若两段没有关系，删掉一段或明确分篇。

## 段落功能

每段只有一个主功能：

- 提出事实。
- 解释机制。
- 展示证据。
- 处理反例或异议。
- 作出判断。
- 推动人物选择。
- 给出下一步。

段落开头通常承担方向。结尾通常交出事实、后果、决定或悬念。过渡来自上一个结果如何成为下一个条件，不来自“首先、其次、更深一层”等空句。

## 反向提纲

写完每一节，把每段压成一句话，标记它的功能。然后检查：

1. 段落是否能映射回全文主轴。
2. 删除任意一段是否会丢失独有信息。
3. 证据是否直接支撑所在段落的结论。
4. 相邻段之间是否能说出具体关系。
5. 有没有段落只是重复、预告或总结。

反向提纲出现无法解释的段落时，先删或合并，再修句子。

## 论证结构

对一个重要判断，至少清楚四件事：

- **Claim：** 到底声称什么。
- **Evidence：** 哪项证据支持它。
- **Reasoning：** 证据为何支持这个判断。
- **Limit：** 什么条件下不成立，反证是什么。

不要把“证据存在”当作“含义自明”。读者需要看到从材料到结论的那一步。

## 标题与摘要

- 先写五个以上不同角度的标题，再选择；不要给同一句做同义词替换。
- 标题要突出主体、动作、结果、冲突或问题；用词符合渠道与受众。
- 摘要承担一个任务：给事实、制造继续阅读的理由，或承诺明确收益。
- 标题中的每个断言都要在正文找到依据。
- 平台字数规则会变化，交付前以用户要求和当前界面限制为准。

## 分篇与序列

内容能独立成立时做一篇；只有共享主轴、连续证据或明确读者路径时才做系列。系列要写清每篇的问题、上一篇如何引出下一篇、读者从哪开始。不要为数量拆碎一个完整论证。

## 分布与复用

设计一次生产、多次分发：

- 长文提取明确答案、单独成立的段落、数据卡和一段短文。
- 适配渠道时改阅读节奏、入口和 CTA，保留事实与核心判断。
- 同一主张在不同渠道用不同长度与语气，不做机械复制。
- 分发前确认引用、图片、隐私和平台限制。
