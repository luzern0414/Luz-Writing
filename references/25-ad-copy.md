# 25 · 广告宣传文案

## 适用与输入

用于信息流、搜索广告、海报、活动、短广告语和产品促销文案。先完成 [20](20-material-understanding.md)、[21](21-writing-foundations.md) 的共用判断，再用 [06](06-marketing-copy.md) 的证据、差异与 CTA 规则。确定主推对象、目标人群与场景、投放位置、可证明的一个主利益、真实行动和篇幅。

小程序交易与运营文案仍走 marketing-copy；优惠券使用规则、停业公告等不因为短就套成广告。图文笔记、整篇公众号和宣传手册优先走各自场景，必要时借用营销方法。

## 选择一个主信息

按用户的传播目标决定这次要让人认识、理解还是行动。选择读者最关心且证据最强的一项利益，其他信息负责解释和证明。品牌广告可突出识别与记忆，效果广告应让人清楚下一步；不要强制每句广告语都塞人群、参数和 CTA。

创意可以从真实场景、机制、比较、情绪或品牌主张切入，具体性不等于所有文案都必须带数字。比较有可比对象和依据，情绪不伪装成用户证言；素材有限时写清能力本身，不用“第一”“零人工”补差异。

## 从主张到可相信的表达

将主利益与产品实际机制连接，用证据或必要限定支撑。所需条件和主张一起压缩，不能因为广告短就省掉专业版、选配、指定人群或有限测试的范围。促销要保留价格条件、真实期限与数量。

例如基础款仅支持蓝牙、本地保存且手动导出，就围绕这组能力写；不能从专业款资料借来 Wi-Fi 自动同步。测试中的能力不当现货卖点，未确认的服务不当购买保障。

## 按位置组织

| 位置 | 优先写清 |
| --- | --- |
| 信息流标题与正文 | 读者相关的入口、主利益、最少必要证明或条件 |
| 搜索广告 | 对应搜索意图的产品与差异、实际能去的下一步 |
| 海报与活动 | 主事件或利益、必要时间地点与条件、真实行动 |
| 广告语／Slogan | 品牌或品类识别、可记住的主张和合适节奏 |
| 落地页首屏 | 人群与用途、主利益、可信依据和下一步 |

遵守实际字段容量，标题、正文、图片上的字和落地页兑现同一个承诺。落地页还没提供的价值不能写成点击后必得。只要求一句广告语就交一句；用户要求多个版本时，切换真实的主张或入口，不做同义词变体。

## 行动与交付

行动说明动词、获得什么及必要条件，不虚构“免费”“立即到账”“无需注册”。留资、付款和续费需要的实际条件按已有产品政策写。没有要求或不适合行动入口的品牌短句，不强行补“立即购买”。

只交用户要的字段和数量。法律与平台边界按 [06 › 合规](06-marketing-copy.md)、[10](10-channels-and-formats.md) 核对；遇到问题直接采用有依据的写法，不自动附带风险报告或 A/B 方案。

## 成稿复核

- 读者能识别主推对象和主利益，文案没有同时抢讲过多卖点。
- 主张有材料依据，型号、版本、价格、期限和例外在压缩后没有丢失。
- 竞品能完全照用时，检查是否遗漏本产品的真实差异；没有差异证据时不编造。
- 标题、正文和落地页一致，CTA 可执行且兑现。
- 字段、数量、字数符合请求，朗读没有歧义或生硬口号。
