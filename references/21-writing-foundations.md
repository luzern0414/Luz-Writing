# 21 · 写作基础与成稿复核

## 共用写作顺序

先完成 [20](20-material-understanding.md) 的最小理解闭环，再选一个有材料支撑的主轴，安排段落或页面职责，成稿后回到源材料复核。每一层的结果供下一层使用：理解结果 → 核心主张 → 内容顺序 → 成稿 → 复核。用户只要求提纲时止于提纲，只要求定点修改时止于指定范围。

## 选定主张和读者价值

把“产品有什么”转成“谁在什么场景里为什么需要知道”。明确读者已知道什么、哪里有疑问、看完能够做什么判断。先解决最影响理解或决策的问题，背景和术语按需补充。

一篇或一条内容有一个主轴；多页可以分担多个支撑点，但要服务同一阅读任务。稿件同时想完成科普、品牌宣言和促销时，按用户的主要目的取舍。并非每篇内容都需要购买、关注或留资入口，行动要求只在任务需要且事实允许时出现。

## 安排段落和页面职责

沿读者需要的顺序组织：先补理解所必需的信息，再给解释、证据、比较或选择。具体结构仍按 [03](03-strategy-and-structure.md) 选择，不固定套“痛点—方案—升华”。

`raw/03-outline.md` 记录“段落／页面、读者问题、本段主张、证据或材料定位、与前后内容的关系”。内部按需要增减字段，不把这张过程表自动交给用户。相邻两页只有同义复述时，合并或换成真正缺少的信息；用户指定页数时重新分配职责，不凑空白口号。

标题提出可兑现的承诺；开头尽快让读者看见与自己的关系；中段每次推进一个判断；结尾完成本次阅读任务。信息型文章可以落在解释或边界上，广告可以落在真实可执行的行动上。

## 写出具体而自然的正文

用对象、动作、机制、后果解释价值。事实之后补上读者理解它所需的那一步，而不是只堆数据或重复“因此更高效”。把功能转成收益时保留版本、型号、前置条件和证据边界。

语气依读者、关系、品牌和样本决定。短句与口语不自动代表自然；幽默、类比、观点和第一人称按内容需要使用。实用清单、产品规格和严肃说明可以直接进入信息，不强制每段有比喻、短评或反转。去机器腔和保声改写继续按 [04](04-natural-expression.md) 与 [12](12-voice-profile-and-learning.md)。

## 按交付对象组织内容

| 对象 | 内容组织单位 | 需要说明的关系 |
| --- | --- | --- |
| 图文笔记 | 封面与各页信息、配文 | 每页新增什么，图片与文字如何互补，配文补什么 |
| 公众号文章 | 主轴、段落与小节 | 观点如何展开，证据如何支持，前后如何衔接 |
| 产品宣传手册 | 整本阅读顺序、每页或跨页 | 客户如何从用途走向场景、机制、证明和选择 |
| 广告文案 | 投放位置里的主信息与必要说明 | 主利益、证据、成立条件和行动是否一致 |

以上是内容职责，不是默认交付清单。用户只要正文就交正文，只要一句广告语就交一句；标题、摘要、封面字、标签、图示说明和多个版本仅在请求包含它们时交付，完整规则见 [15](15-deliver-only-what-was-asked.md)。

## 从大到小复核

1. **理解与覆盖：** 稿件是否回答原任务，关键资料是否读到，必须保留的信息和限制是否落在恰当位置。
2. **事实与推导：** 核心主张能回到原文，机制到价值的推导没有越界，草稿到标题与短文案没有丢失条件。
3. **结构与兑现：** 每段或页有独立作用，证据在需要的位置，标题和结尾没有新增承诺。
4. **声音与表达：** 术语、句式、人称和篇幅匹配读者及样本，删去套话后仍有清楚的解释。
5. **场景与范围：** 数量、字段和格式符合本次请求；跨渠道重写入口与节奏，同时保留同一事实边界。

按 [11](11-quality-gates.md) 及场景卡复核；机器检查只证明可判断的格式和文件条件。对写作效果的改进，用含原始资料的实际请求前后比较，不以“读过规则”“填完表格”或自动检查通过代替。
